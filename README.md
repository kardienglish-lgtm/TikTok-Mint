# TikTok Mint

TikTok Mint is a community-oriented modification project for experimenting with TikTok interface customization.

> **Status:** Work in progress. This repository currently documents the project; the complete source tree and a verified build still need to be published.

## Project goals

- Customize the settings interface and dialogs.
- Improve font selection and provide a font-weight control.
- Redesign region and appearance pickers.
- Keep project information and community links easy to find.
- Document limitations clearly instead of claiming untested features work.

## Development notes

The settings redesign has been worked on in a separate source workspace. The proposed changes include modal settings dialogs, a searchable region picker, font preview, and appearance options. These changes have not yet been verified in a complete Android build or on a device.

Automatic sending of arbitrary text messages is **not implemented**. Any streak-related text template should be treated as a manual/copyable template, not an automatic messaging feature.
